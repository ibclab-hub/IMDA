1. The main page of IMDA
  1. Click the ‘Go to browse results’ card to navigate to the “Browse results” tab, where users can access the list of the results for comparative analyses stored in the database, along with related information.
  2. Click the ‘Go to compare genomes’ card to navigate to the “Compare genomes’ tab, allowing users to perform comparative genomic analyses.
  3. Click the ‘Go to an example browsing page’ card to try IMDA with the comparison results for human, chimpanzee, and mouse.
2. Browse the results of compared genomes in the ‘Browse results’ tab
  • In the ‘Browse results’ tab, the list of pre-generated results of compared genomes for various species combinations and related information are provided.
  1. Search the results of compared genomes using target species or assembly IDs.
  2. Filter columns for detailed information about each result to display only the desired information.
  3. The list of results currently available in IMDA are displayed. Click the “Accession ID” to move to the browsing page for the corresponding result. Click the “Link” button in the “Synteny download” column to download the compared result.
3. Compare multiple genomes in the ‘Compare genomes’ tab
3.1 Perform comparative genome analyses
  • If the result between desired species or assemblies is not available in the ‘Browse results’ tab, users can manually select assemblies in the ‘Compare genomes’ tab for comparative genome analyses.
  • A single reference genome and one or more target genomes can be used.
  1. Select a genome assembly to use as the reference genome for comparative analysis. Only one assembly can be selected.
  2. Select assemblies to use as target genomes for comparative analysis. Multiple assemblies can be selected, excluding the chosen reference genome.
  3. Search for species or gene assemblies to easily select their assemblies of interest.
  4. The "Unselect all" button allows users to deselect all selected species. Assemblies are organized in an accordion by taxonomy, and users can easily manage the list with the "Expand all" and "Collapse all" buttons.
  5. After selecting the reference genome and target genomes, click the "Search prebuilt results" button to check if a prebuilt comparative analysis result for the selected combination exists in the database.
  6. If the result already exists, a table is displayed with the Accession ID link for the browsing page.
  7. If there is no prebuilt result exists for the selected assemblies, users can perform their own comparative analysis. Adjust the synteny resolution value, provide an email address for progress updates, and click the "Submit" button to begin the analysis.
3.1 Perform comparative genome analyses
  • Once the comparative analysis successfully begins, a new webpage for job monitoring automatically opens to display its progress.
  • After finishing the comparative analysis, IMDA sends an email to the user's contact address. This email includes a link to the browsing page for the analysis results.
  1. Click the copy icon to copy the URL of the webpage showing the current job status for the user’s session.
  2. Monitor the status of each analysis. The job status updates every 30 seconds, and users can stop the ongoing analysis easily by clicking the “Quit job” button in the “Status” column.
4. Visualize multi-omic data in IMDA
4.1 Visualize the results of comparative genome analyses

(1) The ‘Genome comparison and annotation’ track setting panel
  • Configure visualization settings for genome comparison (genome conservation and alignment gap) and gene annotation tracks (See details in the ‘7. Multi-omic data tracks in IMDA’ section).
  1. Set the resolution value of synteny blocks.
  2. Select assemblies and enter genomic regions of interest and click the “Go button” to navigate to specific genomic region. This also displays corresponding regions in other assemblies (See details in the ‘6. Explore multi-omic data across species and samples’ section).
  3. Choose the visualization type of genome assemblies (linear or circular).
  4. Change the order of tracks by dragging the track settings.
  5. Adjust the parameters for the ‘Genome comparison and annotation’ track.
  6. Confirm available genome comparison and annotation and filter tracks using the table header.
(2) The ‘Genome comparison visualization’ panel
  • This panel visualized the selected genome assemblies and syntenic regions.
  1. Colored boxes show the chromosomes of the reference and target genome assemblies. Double-click the chromosome block to zoom the track view into the corresponding chromosome (See details in the ‘6. Explore multi-omic data across species and samples’ section).
  2. Syntenic relationships are visualized as gray-colored ribbons. Double-click these synteny ribbons to zoom into the corresponding regions.
  3. The view controller for each genome is provided for manipulating the genomic view of tracks, including zooming and moving (See details in the ‘6. Explore multi-omic data across species and samples’ section).
  4. Confirm detailed information for the chromosome by hovering the mouse on the chromosome block.
  5. Confirm detailed information for the synteny block by hovering the mouse on the synteny ribbon.
4.2 Visualize the multi-omic profiles
(1) The ‘Omics data profiles visualization’ panel
  • This panel visualizes multi-omic data profiles, including gene expression, methylation, histone modification, and chromatin interaction (See details in the ‘7. Multi-omic data tracks in IMDA’ section).
  • Each omic data profile is visualized as an individual track. Explore multiple omic data profile tracks using various manipulation (See details in the ‘6. Explore multi-omic data across species and samples’ section).
  1. The cursor dynamically indicates the aligned position between genome assemblies. If no alignment exists, it turns red.
  2. Syntenic regions are highlighted with background colors.
(2) The 'Omics data profiles' track setting panel
  • This panel allows users to configure visualization settings for the 'Omics data profile' tracks (See details in the '7.Multi-omic data tracks in IMDA' section).
  1. Change the order of tracks by dragging the track settings.
  2. Set the y-axis range automatically or manually.
  3. Change the visualization type for each track. Bar, line, area, point plots are supported for gene expression, methylation, and histone modification profile tracks, while interact-line, interact-ribbon, and heatmap can be chosen in the chromatin interaction profile track.
  4. Set the downsampling method for each track.
  5. Confirm available omics data profile tracks and filter tracks using the table header.
4.3 Visualize the multi-omic signatures
  1. Lollipop plots in the ‘Genome comparison visualization’ panel represent the distributions of multi-omic signatures, and the size of each circle indicates the number of multi-omic signatures. Double-click a lollipop to change the track view to that region.
  2. Multi-omic signatures are highlighted with boxes in the omic data profile track.
  3. The ‘Multiple omics data comparison’ track setting panel.
    • This panel allows users to configure visualization settings for multiple omics data comparison tracks (See details in the ‘7. Multi-omic data tracks in IMDA’ section).
  1. Change the order of tracks by dragging the track settings.
  2. Set the region summary method for each track.
  3. Filter multi-omic signatures for visualization using cutoff values, including top percentile, standard deviation, p-value, and q-value (See details in the ‘6. Explore multi-omic data across species and samples’ section).
  4. Change the color for each multi-omic signature.
  5. Confirm available multiple omics data comparison tracks and filter tracks using the table header.
5. Perform multi-omic data analyses
  • If the desired omics data profiles or multiple omics data comparison results are not listed in the available tracks, multi-omic data analyses with the user-selected datasets can be performed.
  1. Monitor the status of ongoing multi-omics data profile analyses. Progress updates every 30 seconds, and ongoing analyses can be stopped using the "Quit job" button.
  2. New job submission panel for omics data profiling: IMDA supports gene expression, methylation, histone modification, and chromatin interaction profiling. Select the type of analysis and omics data for profiling and set the parameters for analyses.
  3. New job submission panel for multiple omics data comparison: IMDA supports intra-species and inter-species comparisons using four types of omics data profiles. Select the type of analysis and omics data profiles. Based on the number of species involved, intra-species or inter-species comparisons are automatically determined.
  4. Enter an email address to receive notifications upon completion of the analysis.
  5. Click the ‘Submit’ button for performing multi-omic data analyses.
6. Explore multi-omic data across species and samples
6.1 Track view manipulation using the mouse
  • Click and swipe the track to move the track view.
  • Drag the cross-shaped mouse cursor in the bottom of the track to select the region that users want to zoom into, then click the “Zoom in” button in the popup window to focus on the selected genome region.
  • Use the mouse scroll wheel to zoom in and out of the track view.
6.2 Track view manipulation using the brush
  • The brush is a gray box provided for each assembly in the "Genome Comparison Visualization Panel", indicating the currently visualized genome region on the “Omics data profiles” and “Multiple omics data comparison” tracks.
  • Drag the brush to the genomic position of interest to change the track view.
  • Adjust the size of the brush to zoom in on a narrower region or zoom out to view a broader region of omics data.
6.3 Track view manipulation using the search function
  • Select a species and enter a genomic coordinate (e.g., chr1:1000-10000) or gene name (e.g., BRCA1) in the search field to navigate to the specified region and its corresponding regions in other assemblies.
6.4 Other track view manipulation methods
  • Double-click a chromosome box in the "Genome Comparison Visualization Panel" to zoom into that chromosome and its corresponding regions in other assemblies.
  • Double-click a synteny ribbon in the "Genome Comparison Visualization Panel" to navigate to the corresponding synteny region in the assembly.
7. Multi-omic data tracks in IMDA
7.1 The ‘Genome comparison and annotation’ track
  1. Gene annotation: This track visualizes the positions of genes in the genome.
    • If the “Visualization level” is set to “Gene”, genes are displayed as single boxes.
    • The positions of exons, introns, and gene orientation are displayed if it is set to "Exon and Intron".
    • The "Minimum gene length (bp)" determines the minimum length of genes to visualize.
  2. Genome conservation (Entropy): Based on genome alignment data, this track shows the level of genome conservation for each base position relative to the reference genome. Higher values indicate lower conservation.
  3. Genome alignment gap (Proportion): Based on genome alignment data, this track shows the proportion of alignment gaps for each base position relative to the reference genome.
7.2 The ‘Omics data profiles’ track
  • Gene expression: This track shows the expression levels (TPM values) for each gene.
  • Methylation: This track shows the degree of methylation (frequency of methylated Cytosine bases) at each base position.
  • Histone modification: This track displays peak scores for identified histone modification regions.
  • Chromatin interaction: This track shows the interaction levels between different regions in 3D genome space (number of mapped Hi-C reads).
7.3 The ‘Multiple omics data comparison’ track
  • Intra-species comparison: This track shows standard deviation values for each base position calculated using profile data from different samples. Higher values indicate greater variation in profiles at that base position.
  • Inter-species comparison: This track shows the gradient values predicted by linear regression using profile data from different species as X and Y-axis data.
    • Higher absolute values indicate greater differences in profiles at that base position.
    • Negative values indicate a negative linear relationship between species profiles, while positive values indicate a positive linear relationship.
