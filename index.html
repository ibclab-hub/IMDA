IMDA: Integrative Multi-omic Data Analyzer

A web application for integrative analysis and visualization of multi-omics data for multiple genomes

IMDA(Integrative Multi-omic Data Analyzer) is a web-based application for comparative multi-omic data analyses.
Researchers can use IMDA to (i) generate the integrative and genome-wide profiles of multi-omic patterns through a user-friendly web interface
and (ii) visualize and explore them across species through a feature-rich web interface.

The comparative multi-omic data profiler in IMDA generates various multi-omic profiles while supporting cross-species and cross-sample comparative analyses.
Using the user-friendly interface, researchers can easily configure analysis types, datasets, tools, and parameters, and monitor job progress in real-time.

The comparative multi-omic data visualizer can visualize the generated multi-omic data, and multi-omic data
within the genomic regions of interest can be easily explored through a feature-rich web interface.
Additionally, large datasets can be visualized smoothly and flawlessly using efficient sampling and indexing techniques.

* IMDA currently supports only datasets in the IMDA database. If you have specific data you'd like to analyze, feel free to contact us via email.
